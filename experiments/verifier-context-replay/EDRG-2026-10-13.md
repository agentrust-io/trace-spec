## What is actually implemented

1. TRACE reference `verify_record` and `verify_record_report` accept explicit verification time; regression tests cover inclusive stale/future boundary and invalid input.
2. Separate independent verifier imports **no** TRACE verifier or validation logic; verifies canonical RFC8785/JCS Ed25519 signatures, pinned JWK binding, freshness, nonce, frozen revocation, and independently evaluates the **published JSON Schema file** with required format checker.
3. Deterministic fixture differential tests include signed schema-invalid records, signature mutation, root substitution, revoked thumbprints and `kid`, nonce denial, freshness cutoffs and policy tampering.
4. Retained evidence bundle holds exact record/root/policy/revocation/resolver bytes plus context. Evidence digests are recomputed. `replay_bundle.run` demands a **separately supplied manifest SHA-256 anchor**, rechecks retained byte integrity, binds policy bytes to the signed `policy.bundle_hash`, and feeds the same frozen record, trust root, revocation identifiers and time to both implementations. Divergence is `not-established`, never acceptance.
5. Repeated tests on two online hosts of different Python minor versions.

## Release decision and boundaries

- **Replay of cryptographic and declared context checks: PASS within defined offline scope.**
- **Cross-host test reproducibility: PASS.**
- **Independent signed/externally authenticated attestation by a separate reviewer: NOT ESTABLISHED.**
- **Policy semantics beyond matching signed policy digest, and remote resolver or revocation protocol semantics: NOT ESTABLISHED.** Retaining arbitrary resolver bytes proves only integrity against the pinned manifest; it does not prove the resolver source is authoritative or that application policy interpreted those bytes correctly.
- **Full TRACE ecosystem conformance and production release: NOT ESTABLISHED.** The two verifiers intentionally share standard cryptographic and schema libraries, but not TRACE verifier code.

No production keys or external AI models used. Do not merge the experimental PR as production conformance. External manifest pinning is mandatory; a self-declared checksum provides no independent authenticity.
